# 班主任工作台 README

## 项目简介

班主任工作台是一套面向学校班主任与年级管理员的成绩、学生、日程管理工具，数据存储在 Supabase，前端部署在 GitHub Pages 与 Cloudflare Pages。

主要能力：

- 管理员账号 `admin`，密码 `111`，可查看和切换全部班级。
- 班主任用班级号登录（如 `1`、`2`），默认密码 `111`，只能查看和操作本班。
- 学生按身份证号为主键管理，支持家长信息、备注、添加、删除。
- 成绩支持 Excel 批量导入，自动识别考试、计算班内排名，也支持管理员逐人修改。
- 成绩分析展示全部科目原始分/赋分、班排名、校排名、总分与排名。
- 管理员填写的日程和提醒对所有班主任可见，班主任自己添加的日程和提醒只自己可见。
- 数据可导出为 Excel 备份。

## 使用方式

### 1. 登录

- 管理员：账号 `admin`，密码 `111`。
- 班主任：账号为班级号，例如 `1`，密码默认 `111`。
- 班主任的姓名和密码可以在“设置 → 班主任账号”中修改，管理员可修改所有班级。

### 2. 工作台

- 管理员可在右上角切换班级，默认“全部班级”。
- 显示近期提醒、各科平均分、班级/全体平均分、进步退步榜、学生成绩排行。
- “快捷操作”包含：录入成绩、学生管理、成绩分析、添加提醒。

### 3. 录入成绩（Excel 导入）

1. 在工作台点击“快捷操作 → 录入成绩”。
2. 先填写“考试时间”。
3. 选择 Excel 文件（.xls / .xlsx / .csv），文件名会自动作为考试名称。
4. 预览确认学生数和成绩条数后点击“确认导入”。

Excel 列顺序必须与期末成绩表一致：

`身份证号、班级、姓名、政、历、地、物、化、生、总分校赋分、总分校名次、语文、校名次、数学、校名次、英语、校名次、政治、政治校赋分、政治校名次、历史、历史校赋分、历史校名次、地理、地理校赋分、地理校名次、物理、物理校赋分、物理校名次、化学、化学校赋分、化学校名次、生物、生物校赋分、生物校名次`

导入规则：

- 语数英读取原始分和校名次。
- 选考三科读取原始分、赋分和校名次（选科由“政历地物化生”标记列决定，选 3 门）。
- 总分读取“总分校赋分”并存入总分原始分字段。
- 总分 = 语数英原始分 + 选考三科赋分。
- 班内排名由系统自动按班级计算：总分按赋分、选考科按赋分、语数英按原始分，同分同名次。

### 4. 学生管理

- 管理员可切换“全部班级”或具体班级，班主任固定在本班。
- 列表显示姓名、身份证号、班级、选科，不显示成绩和排名。
- 点击学生姓名可查看该生所有科目成绩、原始分/赋分、班排名、校排名。
- 管理员可在学生详情中点击“编辑成绩”修改原始分/赋分，保存后自动重算总分和班内排名。
- 班主任可以编辑本班学生的家长信息（父母姓名、电话、微信）和备注，不能修改成绩。
- 支持添加学生、删除学生、批量删除、按姓名或身份证号搜索。

### 5. 成绩分析

- “趋势”视图：班级平均分历史柱状图，按考试选择查看学科平均分。
- “学生排名”视图：显示所有学生的总分赋分、班名次、校名次，以及语数英政史地物化生各科的分数和班/校排名，支持按总分或任一科目排序。

### 6. 日程安排与近期提醒

- 管理员添加的日程/提醒对全体班主任可见。
- 班主任添加的日程/提醒只自己可见。

### 7. 设置

- 当前账号信息。
- 班主任账号管理：修改各班主任姓名和密码。
- 考试管理：添加考试、设置考试日期、删除考试（会同时删除该考试全部成绩）。

### 8. 数据导出

- 工作台和成绩分析页提供“导出 Excel”，导出学生名单（含家长信息）和成绩明细（含原始分/赋分/班排名/校排名）。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

需要配置环境变量：

```env
VITE_SUPABASE_URL=https://你的项目.supabase.co
VITE_SUPABASE_ANON_KEY=你的匿名公钥
```

## 技术栈

- React 18 + TypeScript + Vite
- Tailwind CSS
- Zustand 状态管理
- React Router
- Recharts 图表
- Supabase（PostgreSQL + PostgREST）
- SheetJS（xlsx）Excel 解析
- vite-plugin-pwa 离线支持
